# Design reference and visual quality

Read before creating a deck or changing its visual direction, within the current confirmation stage. This production workflow must deliver professional, usable design. Passing file, text and overflow checks does not establish visual quality.

## Establish an actual reference

Inspect local or connected user-approved presentation references, templates and production capabilities first. Open the selection response with the local availability result and what has actually been tried, before recommending alternatives. Distinguish a callable production skill, an installed but untested tool, a template with editable masters, and a style reference. A familiar brand name or a skill description is not evidence of output quality or availability.

Use the reference the user has already selected. When no choice is established, show the suitable local options and ask which is primary. If the user explicitly delegates the choice, select the strongest fit and state it. Do not reopen a settled choice at every chapter. A correction to an existing deck inherits its established design unless the request changes it.

If no suitable local reference or capable production method is available, research five strong current options for this task and ask the user to select one before designing. Explain each option's applicable audience, visual character, reason for recommendation, actual access path and material constraints. Use first-party links and inspect examples. Present a reasoned shortlist, not an unsupported claim of a universal top-five ranking. A proprietary internal skill must not be described as obtainable merely because its product exists. Continue independent content and engineering work while the choice is pending; do not substitute an arbitrary template. Skipping reference confirmation requires the user's explicit authorization.

Stage 4 also requires the five verified auxiliary PPT-skill and writing-skill recommendations in external-handoff.md, even when a primary local reference exists. Do not conflate local reference discovery with that producer-handoff requirement.

## Translate the choice into production

Name one primary design source and, if needed, a specifically bounded secondary source. Record which qualities carry over: typography hierarchy, palette, grid and spacing, evidence/diagram treatment, imagery and chapter rhythm. Inspect representative reference pages rather than borrowing only a cover or brand colors. The new subject, audience and density still determine page composition. Do not copy private business claims or imply endorsement by a reference's author.

Keep a short design brief with source locations, retained qualities, necessary adaptations and the selected execution capability. Use existing assets or templates when they fit and are permitted. Embedding third-party skill code, templates, fonts or images in a distributable package requires appropriate rights and provenance; linking or invoking an available capability does not require copying its implementation. Private style references remain local unless sharing is authorized.

Before expanding a long deck, produce representative pages using its real content, including a dense page and a relation/data page where applicable. Compare these with the chosen reference at readable size and correct concrete weaknesses. This is producer quality control; it is not another mandatory user approval when the visual direction is already settled.

## Judge the complete result

Inspect all rendered pages, and detailed views wherever the overview cannot show legibility or relationships. Compare applicable pages side by side with the selected reference. Judge whether the reader can find the main point, follow the supporting evidence, read the labels and understand the next action at the intended viewing size.

Repair inconsistent alignment/spacing, weak contrast, cramped or irregular type, incorrect chart scales and diagram relationships, unexplained dense blocks, poor crops and distracting ornament. Review the whole deck's rhythm: do not turn unrelated explanations into the same repeated card grid merely because it is easy to generate. Repetition is appropriate for genuinely parallel comparisons; layout variety must serve meaning rather than decoration.

A polished cover cannot compensate for rough interior pages. Preserve evidence and necessary qualifications while improving layout; splitting a page is preferable to hiding meaning in unreadable text. Complete both this visual judgment and the separate content, native-file and target-application checks. When a quality requirement remains unmet, state the concrete page-level problem and continue the authorized correction; do not label the result professional solely because export succeeded.
